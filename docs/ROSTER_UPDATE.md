## Реализация

- main.members содержит только текущие UUID API; main.archivedMembers сохраняет отсутствующие UUID, все оценки, комментарии, даты и авторские дополнения.
- totalParticipants равен длине текущего members. Максимум оценок, прогресс, остаток, статусы, прогноз, таблицы и индексы используют эту актуальную выборку.
- При возвращении UUID сборщик извлекает старые авторские поля из архива; текущие оценки берёт из API. Новый UUID автоматически добавляется в members.
- Каждый сбор читает data/forum.csv, проверяет уникальность UUID и группы, затем обновляет forum_judges_export.json по точным идентификаторам.
- normalizeData передаёт интерфейсу только текущие UUID и пересечение с CSV. Полный авторский справочник сохраняется отдельно как referenceMetadata.
- Исторические записи не удаляются при переносе в архив. В history.json добавлены неизменяемые версии выборки и отдельные selectionChanges. Сравнение sameGradesComparison показывает эффект смены состава на одинаковых оценках; он не выдаётся за изменение отношения судей.
- Формулы calculations.js, general.js, personal.js, модели прогноза и статусов не менялись. CSS, HTML, навигация, таблицы, фильтры и обработчики V108 сохранены.
- tracker.py изучен как дополнительный материал. Его индекс из двух относительных преимуществ и прогноз по суткам отличаются от действующего сайта; они не перенесены. sample_live.json остаётся историческим примером.
