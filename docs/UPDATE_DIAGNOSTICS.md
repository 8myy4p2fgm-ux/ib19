## Значение «Обновлено»

app.js показывает D.updated = exportedAt основного JSON, форматированное в Europe/Moscow. Это время завершения успешного сбора, а не запуска, последней оценки или публикации. collector вызывает now() после чтения и сверки с live, даже когда новых оценок нет. В fetch-data.mjs это же значение попадает в exportedAt / lastSuccessfulAt / runId metadata. Тест без новых оценок подтверждает: время выгрузки новое, исходные даты оценок прежние.

data.js запрашивает metadata с cache:no-store и уникальным check; основные JSON — с версией runId, с проверкой согласованности exportedAt. Ранее открытая вкладка не опрашивает новые данные: нужна перезагрузка страницы. Это существующее поведение, в рамках диагностики интерфейс не менялся.

При сбое основной попытки metadata не обновляется, резерв остаётся разрешённым.
