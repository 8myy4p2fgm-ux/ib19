# Обзор v6 и экран загрузки

Эталоны: TUZ_V95_overview_v6.html и TUZ_V95_carrot_loader_preview.html, сохранённые в docs без изменений. Демонстрационные данные из них не используются в рабочем приложении.

## Изменения

- index.html: нижняя часть «Обзора» дословно по v6; четыре статуса, зелёно-красная шкала, постоянно открытая таблица трёх групп, распределение 0–5 и сравнение средних справа. Пустое скрытое состояние ошибки заменяет прежнюю надпись загрузки; морковка размещена в начале body.
- css/styles.css: 18 блоков эталона «Обзора» в исходном порядке и CSS морковки. Прочие разделы сохраняют исходные блоки. Для fade лоадера добавлено !important: глобальный запрет переходов статичного сайта иначе отменял бы согласованные 0,3 секунды.
- js/app.js: представление общих статусов и распределение полученных оценок из действующих участников; сообщение готовности лоадеру после подготовки интерфейса или корректной ошибки. Формулы и методы определения статусов прежние.
- js/loader.js: 68 px, один оборот за 1 секунду, линейное непрерывное вращение; отсчёт 2000 мс начинается немедленно. Данные загружаются параллельно. Начало исчезновения — max(2000 мс, готовность аналитики/ошибки). Исчезновение занимает 300 мс, узел удаляется через 350 мс. Обычная навигация не создаёт его снова.
- tests/browser.mjs, ui-reference.mjs, ui-reference.test.mjs, loader.mjs: эталоны и тесты обновлены.
- README.md: описание интеграции и проверок.

## Расчёты

Для процентов прошедших/выбывших знаменатель — исключительно прошли + выбыли. При отсутствии определённых исходов выводится «—», полосы имеют нулевую ширину. Распределение числа оценок строится по каждому текущему участнику; доли считаются от числа всех текущих участников. Для визуальной длины полос применяется масштаб максимальной категории, как в эталоне. Средние оценки и группировка не менялись.

На проверенной выгрузке от 12.10.2026 23:21 МСК:

- участников 3285; в борьбе 2452; прошли 607; выбыли 226;
- определённых исходов 833; прошли 72,9%, выбыли 27,1%;
- распределение 0–5: 498 / 705 / 671 / 503 / 317 / 591; сумма 3285;
- группы: Форум 64, Ветераны 29, Остальные 3192.

Данные, JSON, CSV, история, индексы, прогноз, сопоставление UUID, GitHub Actions, Cloudflare, DNS и конфигурация Pages не изменены.

## Проверки

Node-тесты: регрессии формул и исторических значений, актуальная выборка, точность CSS и неизменность интерфейсных рендереров остальных разделов.

Браузер: «Обзор» сравнивается с v6 на актуальных данных; три остальных раздела — с предыдущим согласованным эталоном. Ширины 1440, 1024, 768, 390, 320 px; состояния раскрытий, наведения, фильтры, сортировки, подсказки, окна участников/комментариев. Скриншоты и comparison.json — docs/screenshots/ui-reference/ (CI artifact, не исходные данные).

Лоадер: сравнение снимков с эталоном на 1440/390 px при остановленном вращении только для скриншота; проверка настоящего CSS-вращения, быстрой загрузки, задержки данных 3200 мс, ошибки HTTP 503, обновления страницы и внутренних переходов. Проверены числа и проценты новых блоков относительно текущей базы.

Результат локального запуска: 20 Node-тестов пройдены, 65 пар скриншотов без обнаруженных различий; оба снимка лоадера совпали с эталоном. Сценарии fast/slow/error пройдены, ошибок JavaScript нет. validate и build завершились успешно.
