TUZ19 — «Хо-ро-шо. По форумному»

Локальная интеграция согласованного V6. База: 8323690.
Публикация, коммит и сбор данных в рамках этой задачи не выполняются.

АРХИТЕКТУРА
Маршрут /horo/ обслуживается общей оболочкой и штатным js/routes.js.
Навигационный знак доступен на всех страницах. В текущем main отсутствует
«Лаборатория», поэтому знак следует непосредственно за «Рэперами».
Новая секция не участвует в расчётах и не изменяет аналитические данные.
js/horo-entry.js загружает код и контент только после открытия раздела.
Тексты выводятся как безопасный текст, а не произвольный HTML из JSON.
Существующие стили, фон, выключатель и логотип не заменяются файлами из V6.

КОНТЕНТ
horo/content.json — единственный манифест, порядок элементов соответствует
порядку отображения. Исходные изображения лежат в horo/media/.

Чтобы добавить сводку:
1. В начало summaries добавьте объект с number, title и paragraphs.
2. paragraphs — массив полных абзацев, с исходной авторской орфографией.
3. Все выпуски по умолчанию свёрнуты; открытие нескольких не ограничивается.

Чтобы добавить видео:
1. В videos добавьте url (YouTube embed), link (обычная ссылка) и title.
2. Не добавляйте autoplay. Встраивание адаптивное, loading=lazy.
3. Обычная ссылка показывается всегда, в том числе при недоступности плеера.

Чтобы добавить картинку:
1. Скопируйте исходный файл в horo/media/.
2. В images добавьте src вида media/filename.png и содержательный alt.
3. Для серии можно дополнительно задать frames — массив исходных файлов
   в порядке чтения; src указывает согласованную общую миниатюру серии.
4. Текущая история: comic-14.png → comic-13.png → comic-12.png (3 → 2 → 1).
   В просмотре кадры идут горизонтально, на мобильном доступны прокрутка
   и увеличение. Исходные файлы не менялись и не разбивались на кадры.

ПРОВЕРКИ И ЗАПУСК
Node >=22. npm ci; npm test; npm run validate; npm run build;
npm run test:browser.
Локальный сервер: npm run dev -- --dir dist --port 8934
Открыть http://127.0.0.1:8934/horo/
Готовый dist также можно обслужить командой python3 -m http.server 8080
из каталога сборки; file:// не подходит для модулей и JSON.

Браузерный тест tests/horo-browser.mjs проверяет пять ширин, штатные разделы,
сводки, прямой URL, изображение меню, галерею, серию, зум и закрытие Esc.
Внешний YouTube в автоматическом тесте подменяется тестовым ответом:
это проверяет интеграцию iframe, но не воспроизведение самого ролика.
Для реального просмотра нужна доступность YouTube в браузере пользователя.
