# Восстановление интерфейса по IB19_V95_WHITE_TUZ_HEADING.html

Единственный актуальный источник оформления: предоставленный файл, сохранённый без изменений в docs/IB19_V95_WHITE_TUZ_HEADING.html. До правок рабочая версия сравнивалась с ним структурно; разметка, CSS и три интерфейсных модуля были сохранены для контрольного отображения исходной версии.

## Что перенесено и что сохранено

Все 16 блоков CSS скопированы дословно с исходным порядком каскада. Статическая разметка взята из эталона; упакованные данные и inline-скрипты заменены ссылками на поддерживаемые файлы проекта. Интерфейсные модули forum-link, judge-summary и pace-page извлечены из эталона с заменой только модульных импортов/экспортов и исправлением отсутствующего триггера строки.

Данные, справочник CSV, архив, история, сборщик, формулы, модели прогноза/статусов, маршруты, GitHub Actions, DNS, домен и конфигурация публикации не менялись. Cloudflare Web Analytics сохранён в единственном экземпляре перед закрывающим body.

## Проверка

20 Node-тестов проверяют прежние математические регрессии, актуальный состав и точность переноса CSS/рендереров. Playwright проверяет все четыре страницы на ширинах 1440/1024/768/390/320 px. В 65 парах скриншотов страниц, раскрытых примечаний, методологии, выбора судьи, рейтинга ветеранов, фильтров, комментариев, наведения на рейтинг и матрицу pixelmatch не обнаружил различий (threshold 0,1, стандартное исключение антиалиасинга). 62 пары PNG совпали побайтно.

Для эталона в тесте меняется только мост загрузки данных: вместо устаревшей встроенной базы используется действующий загрузчик и актуальная выборка проекта. Визуальные компоненты и интерфейсные обработчики эталона остаются исходными. Проверяются равенство показателей, сортировки, поиск, фильтры групп, подсказки мышью и клавиатурой, закрытие по Escape, модальные окна, переходы, отсутствие новых переполнений и ошибок JavaScript. Отдельно проверяется восстановленное открытие окна участника со строки.

Снимки «до» и пары «эталон / результат» находятся в docs/screenshots/ui-reference/. Каталог исключён из Git; workflow сохраняет его как скачиваемый artifact. Машинный отчёт сравнения сохранён в docs/ui-reference-audit/comparison.json.
