# Аудит и границы миграции V108

Эталон: `docs/V108.html`, неизменённая копия предоставленного V108. Старые версии проекта не использовались как источник интерфейса или расчётов.

## Архитектура

V108 содержит 19 последовательных блоков CSS, 22 модуля JavaScript и четыре дополнительных скрипта взаимодействий. CSS перенесён с сохранением порядка каскада. Модули переведены в ES modules; дополнительные обработчики оставлены в исходном порядке. Разметка, тексты и маршруты сохранены.

Четыре основные страницы: Обзор, Судейские обхваты, Судьи, Реперы. Служебные маршруты и методология сохранены. Основной JSON хранит участников, идентификаторы, оценки, судей, комментарии и scoredAt. Второй JSON задаёт авторские форумские соответствия и группы; сопоставление идёт по userId, а не по никам.

Встроенные данные декодированы из самого V108: 3288 участников, 6062 оценки, 22 судьи, 86 авторских соответствий. Контрольная дата выгрузки — 2026-10-09T09:22:25.473Z. Числовая точность и неизвестные дополнительные поля не сокращены.

Расчёты сохранены в calculations/general/personal и других исходных модулях. Их контрольные результаты для обеих групп и исторических срезов сравниваются с непосредственно исполняемым модулем эталона. Прогноз, статусы и коэффициенты не заменены другой методологией.

## Источник обновления

Публичный API api.19ib.ru найден в клиентском JavaScript официального 19ib.ru. Используются /rounds/{id}/full, /entries/{userId}/scores и /live. Раунд: c3c5b2f7-9d61-4ffc-8f97-f1b50156d59c. Правила источника: пять оценок, шкала 1–5, проходной балл 15. Дедлайн в ответе API — 2026-10-18T20:59:00.000Z; настройки существующих расчётов V108 не изменены.

На момент аудита API возвращал 3285 участников. Три идентификатора из исходной базы отсутствовали. Они сохраняются со всеми прежними оценками и пометкой current:false; причина отсутствия не выдумывается. Авторские сопоставления не удаляются. API не предоставляет надёжного журнала предыдущих исправлений оценок: история исправлений начинается с наших наблюдений.

## Риски

- Полный опрос занимает много минут: не более двух стартов запросов в секунду и две параллельные загрузки. Перед публикацией сверяется актуальный /live.
- При изменении правил, повреждённых ответах или неустранимой рассинхронизации обновление останавливается; последняя опубликованная версия остаётся доступна.
- Исходный V108 уже обрезает крупный индекс на ширине 320 px. Миграция воспроизводит эту особенность; исправление потребовало бы согласованной правки дизайна.
- Расписание GitHub Actions допускает задержки. В интерфейсе показана дата успешных данных, а не часы браузера.
- Общая группа concurrency сериализует публикацию интерфейса и данных, чтобы более старый Pages-артефакт не заменил новый.
