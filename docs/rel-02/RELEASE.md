## Изменения

- Полноценный принятый frontend 2.0: шесть разделов, runtime-модули, CSS/assets, маршруты GitHub Pages. В сборке только достижимый JS-граф, без встроенных демонстрационных данных.
- Утверждённый финальный источник R1 перенесён вместе с исходными файлами, историей, политикой и фиксированным контрактом. Данные не пересчитывались. Бывший переключатель приложения на development baseline удалён; совместимость моделей со старыми данными не переписана.
- Root JSON/CSV, история production и основные формулы сохранены побайтно из main. `r1-archive-lock.json` запрещает их перезапись вместе с финальным источником/политикой. Это контроль целостности, не повторная сверка аналитики.
- Существующий update entrypoint направлен только на pinned R2/submissions. Использован прежний HTTP-клиент с прежними лимитами. Только full/live, без scores/judges; при начале судейства обновление останавливается до отдельного решения.
- В существующем каталоге R2 сохраняются снапшот, raw-ответы, metadata, manifest и история before/after сдач. Отсутствующая дата сдачи остаётся неизвестной и не заменяется временем наблюдения. Новые сдачи/смены трека сохраняются; no-op не меняет набор и не публикуется; ошибка оставляет последний успешный набор.
- Когорта R2 — UUID со статусом pass из действующей утверждённой модели R1. Новых правил расчёта нет. В реестре R2 показана дата сдачи вместо нулевого счётчика оценок. Допуск и сдача разделены; сдачи вне когорты не удаляются и отмечаются отдельно.
- Изменены только существующие workflows: allowlist коммита данных теперь содержит шесть файлов R2; deploy читает свежий main под существующей блокировкой. По ускоренному режиму используются целевые release-проверки и короткий browser smoke, без повторной полной регрессии R1. Прежние полные npm test/test:browser доступны явно. ID workflows, concurrency, permissions и Pages-механизм сохранены.
- Удалены подтверждённо недостижимые старые UI-файлы `css/birthday.css` и `js/pace-page.js`. Общие аналитические модели сохранены. Остатки старых CSS-селекторов не подвергались масштабной чистке.
