# Выполненные проверки

## Расчёты и сборщик

Node-тесты сравнивают исходные расчёты V108 и миграцию: общий и личные индексы для групп форума и ветеранов, компоненты личных индексов и исторические срезы. Проверены валидация пары источников, сохранность ручных полей и комментариев, новые оценки, исправления, отсутствие изменений, отсутствие участника в API, неполные ответы, неверные даты и недоступный источник.

## Браузер

Реальный Playwright Chromium проверил оригинал и проект на ширинах 1440, 390, 320 px, на всех четырёх маршрутах. Проект обслуживался в подпапке /ib19/, как на GitHub Pages. Проверены загрузка JSON, переходы, поиск, фильтр судьи и сброс, трёхпозиционная сортировка матрицы, модальные окна комментария и участника, отсутствие pageerror. Снимки сохраняются в docs/screenshots и как артефакт CI. Нового переполнения относительно V108 не обнаружено; обрезание большого индекса на 320 px присутствует в эталоне.

## Публикация

Локальные проверки не заменяют проверку публичного URL. Пока GitHub push и Pages deployment не завершены, HTTPS-доступ и выполнение GitHub Actions считаются неподтверждёнными. Эта граница явно сообщается в итоговом отчёте.
